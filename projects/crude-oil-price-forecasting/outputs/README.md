# Provisional outputs

Run `python reproduce_oil_workbook.py` with the supplied workbook saved locally as `data/BSOM096_CrudeOilPrice.xlsx` to regenerate quarterly means, holdout forecasts, an eight-quarter forecast, a model-comparison table, an audit summary, and SVG charts. The date normalisation is provisional; confirm the original date convention, benchmark and source licence before relying on the forecasts. Raw data is not included.
